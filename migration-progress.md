# Гибридная версия «АвтоДоговор» 1.0.3

## Цель

Веб-приложение остаётся основным интерфейсом и обновляется без переустановки APK.
Android-приложение становится защищённой гибридной оболочкой и сохраняет текущий
нативный интерфейс как аварийный офлайн-режим.

## Текущая архитектура

- Веб-интерфейс: один адаптивный экран `/`, статические HTML/CSS/JavaScript.
- Сервер: FastAPI и маршруты `/api/*`.
- Мобильное приложение: Expo Router, React Native, SQLite, SecureStore,
  биометрия, OCR и Яндекс Диск.
- Секреты нельзя передавать из нативного SecureStore в удалённый JavaScript.

## Маршруты и способ миграции

| Экран или функция | Решение 1.0.3 |
| --- | --- |
| Веб-форма ДКП `/` | Запускать в защищённой WebView |
| Веб-архив | Запускать в WebView, данные хранит сервер |
| OCR и формирование договора | Оставить на сервере за `/api/*` |
| PIN и биометрия | Оставить нативными, до открытия WebView |
| Нативный архив и редактор | Сохранить как офлайн-резерв |
| Ключи OpenRouter и Яндекс | Не отдавать WebView; хранить в SecureStore или на сервере |
| Камера и выбор файлов | Сначала стандартный HTML capture/WebView, затем нативный мост |
| Фоновая очередь | Следующий этап: нативная задача Android |

## Правила безопасности моста

- Загружать HTTP только для локальных адресов; внешний сервер обязан использовать HTTPS.
- Разрешать навигацию внутри выбранного origin, остальные ссылки открывать внешне.
- Никогда не возвращать в JavaScript OpenRouter API key и OAuth-токены.
- Каждая команда моста должна входить в фиксированный белый список.
- Отключить доступ WebView к произвольным локальным файлам.
