# Проектная память: «АвтоДоговор»

## Цель

Локальное веб-приложение для фирмы автоуслуг. Оно принимает фотографии паспорта, ПТС и СТС, помогает перенести данные в карточку сделки, хранит локальный архив и формирует договор купли-продажи автомобиля для печати через Microsoft Excel.

## Принятые решения

- Первый запуск: один компьютер с Windows.
- Интерфейс и документация: русский язык.
- Архив: локальная база SQLite, без отдельного пароля в первой версии.
- Документы первой версии: паспорт, ПТС и СТС.
- Распознанные значения автоматически подставляются в поля.
- Если значение не распознано, соответствующее поле остаётся пустым.
- Сомнительный и неразобранный текст помещается в поле «Заметки».
- «Заметки» не участвуют в формировании и печати договора.
- Основной результат: файл Excel.
- Рабочий шаблон пользователя имеет формат `.xls`.
- Для сохранения оформления `.xls` используется установленный Microsoft Excel.
- Облачное OCR допускается только как отдельное ручное действие. В текущем MVP оно не включено до выбора поставщика и правил обработки персональных данных.
- Основной OCR: локальная визуальная модель `qwen2.5vl:3b` через Ollama. Windows.Media.Ocr не используется для автоматического заполнения из-за низкого качества на реальных фото.
- Поддерживаются изображения и многостраничные PDF.
- Несколько страниц одного документа загружаются одним комплектом: паспорт (основной разворот + прописка), ПТС/СТС (обе стороны).
- Старый ДКП распознаётся как отдельный вид документа. Печатные поля извлекаются автоматически; рукописные значения считаются сомнительными и обязательно проверяются человеком.

## Реализуемый MVP

1. Карточка продавца, покупателя, автомобиля и договора.
2. Загрузка нескольких фотографий с указанием типа документа.
3. Предобработка изображения и локальное OCR средствами Windows.
4. Автозаполнение известных полей без выдумывания отсутствующих данных.
5. Сохранение сделок, документов и заметок в локальном архиве.
6. Поиск по ФИО, телефону, VIN и госномеру.
7. Формирование резервного `.xlsx`.
8. Заполнение пользовательского `.xls` по настраиваемой карте ячеек через Excel Automation.

## Важные ограничения

- Точность OCR проверяется только на реальных примерах пользователя.
- Паспортные данные и фотографии нельзя передавать облачному сервису автоматически.
- Рабочий файл получен: `MyFiles/BAZA.xls`.
- В книге есть листы `База` и `ДКП`. Приложение создаёт копию файла, записывает сделку в первую свободную строку `База` и устанавливает её ID в `ДКП!L2`.
- Исходный `BAZA.xls` никогда не изменяется.
