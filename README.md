# АвтоДоговор

Локальное веб-приложение для подготовки договоров купли-продажи автомобиля по фотографиям паспорта, ПТС и СТС.

## Web/Cloud/APK 1.0.6

Основная версия работает в облаке по адресу `https://dkp-app.innvinjapan.chatgpt.site`.
Android-приложение открывает её автоматически без Tailscale, VPN и ручного ввода адреса.

- При первом запуске войдите через GitHub; дальше сессия сохраняется.
- Все сделки и фотографии хранятся в облачном архиве отдельно для каждого ДКП.
- Внешний интерфейс обновляется на сервере без переустановки APK. Новая сборка
  APK нужна только при изменении нативных функций.
- В нижнем меню веб-версии постоянно доступны только **ДКП** и **Архив**.
- Светлая и тёмная темы переключаются ползунком в шапке.

## Быстрый запуск

1. Дважды щёлкните `Установить.bat` один раз.
2. Затем запускайте приложение файлом `Запустить.bat`.
3. Откройте `http://127.0.0.1:8765`, если браузер не открылся автоматически.

Все данные хранятся только в папке `data` внутри проекта.

## Рабочий шаблон Excel

Рабочий файл подключён по адресу `MyFiles/BAZA.xls`.

При нажатии «Создать Excel» приложение:

1. Создаёт копию `BAZA.xls`, не изменяя оригинал.
2. Записывает новую сделку в первую свободную строку листа `База`.
3. Переключает лист `ДКП` на ID новой записи.
4. Сохраняет результат в `data/contracts`.

Если `BAZA.xls` недоступен, приложение создаёт резервный `.xlsx`.

## Документы и вложения

Документы загружаются по отдельным графам: паспорт продавца, паспорт покупателя, ПТС, СТС, старый ДКП и прочее.

Поддерживаются вложения: `jpg`, `jpeg`, `png`, `webp`, `heic`, `bmp`, `tif`, `tiff`, `psd`, `pdf`, `xls`, `xlsx`, `doc`, `docx`, `ppt`, `pptx`.

- Наведите курсор на загруженный файл, чтобы удалить его.
- Наведите курсор на сделку в архиве слева, чтобы удалить всю сделку с документами.

## OCR

Основное облачное распознавание теперь может выполнять Yandex OCR. Это доступнее для РФ, хорошо работает с русским текстом, но изображения/PDF отправляются в Yandex Cloud.

### Yandex OCR

1. Создайте API key в Yandex Cloud.
2. Создайте файл `config/yandex_api_key.txt`.
3. Вставьте в него ключ одной строкой.
4. При необходимости создайте файл `config/yandex_folder_id.txt` и вставьте туда `folder_id`.
5. Перезапустите приложение.

Ключ также можно передать через переменную окружения `YANDEX_API_KEY`, folder id — через `YANDEX_FOLDER_ID`. Не отправляйте эти файлы другим людям.

Yandex OCR запускается для `jpg`, `jpeg`, `png`, `pdf`.

### Gemini OCR

Gemini остаётся запасным облачным OCR, если Yandex OCR не настроен.

1. Получите Gemini API key в Google AI Studio.
2. Создайте файл `config/gemini_api_key.txt`.
3. Вставьте в него ключ одной строкой.
4. Перезапустите приложение.

Ключ также можно передать через переменную окружения `GEMINI_API_KEY`. Не отправляйте файл `config/gemini_api_key.txt` другим людям.

Gemini OCR запускается для изображений и PDF: `jpg`, `jpeg`, `png`, `webp`, `heic`, `bmp`, `tif`, `tiff`, `pdf`.

Файлы `psd`, `xls`, `xlsx`, `doc`, `docx`, `ppt`, `pptx` сохраняются как вложения без распознавания.

### Локальный резервный OCR

Если Gemini API key не указан, приложение сохраняет документы и может использовать локальный визуальный ИИ, если он установлен. Фото не отправляются в интернет.

1. Один раз запустите `Установить ИИ.bat`.
2. Будет установлен Ollama и модель `qwen2.5vl:3b` объёмом около 3,2 ГБ.
3. Зелёные поля распознаны уверенно, жёлтые и красные обязательно проверьте.

- Для паспорта выберите продавца или покупателя и загрузите сразу основной разворот и страницу прописки.
- Для ПТС/СТС загрузите обе стороны одновременно.
- Поддержка PDF локальным ИИ дорабатывается; пока предпочтительнее загружать страницы фотографиями.
- Старый ДКП можно выбрать отдельным типом. Печатные данные распознаются лучше рукописных, поэтому результат всегда нужно сверять.

## Резервное копирование

Для резервной копии достаточно скопировать папку `data`. Она содержит базу, фотографии и сформированные договоры.
