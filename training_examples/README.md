# Обучающие примеры OCR для ДКП

Эта папка нужна, чтобы программа постепенно лучше понимала, откуда брать поля в паспорте, СТС, ПТС и старом ДКП.

## Как работать

1. Создайте подпапку для примера, например `001_passport_seller`.
2. Положите туда фото или PDF документа.
3. Откройте файл `cases.example.json`, скопируйте один блок в свой файл `cases.json`.
4. Впишите путь к файлу, тип документа и правильные значения полей.
5. Запустите проверку:

```powershell
.\.venv\Scripts\python.exe tools\evaluate_ocr_training.py
```

## Типы документов

- `seller_passport` - паспорт продавца.
- `buyer_passport` - паспорт покупателя.
- `pts` - ПТС.
- `sts` - СТС.
- `old_contract` - старый ДКП.

## Важные правила

- Если поле на документе не видно, оставляйте его пустым или не указывайте.
- Не исправляйте документ "по памяти". Пишите только то, что реально видно.
- Паспорт: `1234 567890`.
- ПТС и СТС: `1234 567890`.
- Телефон: `+7 (999) 123-45-67`.
- Госномер: только русские буквы, например `У123УХ14`, не `Y123YX14`.
- VIN: 17 латинских символов.
