# АвтоДоговор Mobile

Самостоятельное Android-приложение для подготовки договоров купли-продажи автомобиля.

## Версия 1.0.3 — гибридный режим

Приложение запускает веб-версию с выбранного доверенного сервера и сохраняет
текущий нативный интерфейс как офлайн-резерв.

1. Запустите сервер на компьютере файлом `Запустить для телефона.bat`.
2. Телефон и компьютер должны находиться в одной доверенной Wi-Fi-сети.
3. Введите показанный сервером адрес при первом запуске приложения.
4. Для внешнего адреса приложение принимает только HTTPS.

Ключи OpenRouter и Яндекс-токены не передаются в JavaScript WebView. Кнопка
**Офлайн** открывает прежний нативный архив, если сервер недоступен.

## Что реализовано

- локальный архив сделок в SQLite;
- корзина с восстановлением и безопасным удалением;
- камера и выбор нескольких фотографий;
- паспорт продавца и покупателя, ПТС/СТС, старый ДКП;
- сжатие и поворот фотографий;
- распознавание через OpenRouter;
- ручная проверка спорных значений;
- повторное распознавание разделов;
- создание Excel, PDF и JPG;
- печать и системное меню отправки;
- автоматическая загрузка файлов на Яндекс Диск;
- PIN-код, биометрия и автоматическая блокировка;
- светлая и тёмная темы;
- адаптивный интерфейс телефона и планшета.

Исходные фотографии не отправляются на Яндекс Диск.

## Первый запуск для разработки

```powershell
cd mobile
npm install
npx expo start
```

Для проверки через Expo Go установите Expo Go на Android и отсканируйте QR-код.

## Настройка OpenRouter

1. Создайте ключ в личном кабинете OpenRouter.
2. В приложении откройте **Настройки**.
3. Вставьте ключ в поле **Ключ OpenRouter**.
4. Нажмите **Сохранить настройки**.

Ключ хранится в Android SecureStore и не включается в APK.

## Настройка Яндекс Диска

1. Создайте Android-приложение в кабинете Яндекс OAuth.
2. Укажите package name: `ru.avtodogovor.mobile`.
3. Добавьте разрешение на запись в Яндекс Диск.
4. Используйте схему возврата `autodogovor://`.
5. Скопируйте Client ID в настройки приложения.
6. Нажмите **Подключить Яндекс Диск** и подтвердите доступ.

Файлы сохраняются в:

```text
/АвтоДоговор/<год>/<номер договора>/
```

## Сборка APK

Для первой облачной сборки нужен бесплатный аккаунт Expo:

```powershell
npx eas-cli@latest login
npx eas-cli@latest build --platform android --profile preview
```

Профиль `preview` в `eas.json` формирует APK для ручной установки, а не файл Google Play.

Если вход в Expo недоступен, проект содержит локальный бесплатный сборщик:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\build-local-apk.ps1
```

Локальная сборка выполняется в коротком ASCII-пути `D:\ADK`, поскольку Android NDK
на Windows некорректно обрабатывает кириллицу в пути проекта. Готовый
APK с номером текущей версии автоматически копируется в `mobile/output/`,
например `AutoDogovor-1.0.3.apk`.

## Важные ограничения

- OCR и Яндекс Диск требуют интернета.
- Для Яндекс OAuth нужно один раз зарегистрировать приложение в кабинете Яндекса.
- APK нельзя получить через EAS до входа в аккаунт Expo.
- Персональные данные и секретные ключи не должны добавляться в исходный код.
